# Ana Isabel Beauty assets

These local SVG files are presentation-ready placeholders derived from the
Beauty profile, not copies of the supplied raster reference.

- `ana-isabel-logo.svg`: primary/square mark and professional fallback.
- `ana-isabel-logo-horizontal.svg`: navigation and footer wordmark.
- `ana-isabel-icon.svg`: favicon and installable-app icon.
- `ana-isabel-hero.svg`: local Home hero artwork.

When final vector artwork is supplied, replace these files in place (or set
the corresponding public branding overrides) without changing Barber assets.
